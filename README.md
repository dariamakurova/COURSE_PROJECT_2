# Программа для поиска вакансий на платформах с факансиями, с фильтрацией по ключевым словам и диапазону зарплат, сортировкой по зарплате и сохранением результатов в JSON.

##  Возможности

- Получение вакансий с HeadHunter по поисковому запросу.
- Сохранение вакансий в JSON файл
- Фильтрация вакансий:
  - По ключевым словам в названии, требованиях или компании
  - По диапазону зарплат
- Сортировка вакансий по зарплате
- Вывод:
  - Все вакансии
  - Топ-N вакансий по зарплате


## Установка

Клонируйте репозиторий:
git clone https://github.com/dariamakurova/COURSE_PROJECT_2

## Запуск программы

python -m src.main

Программа запросит:
- Поисковый запрос вакансий.
- Способ вывода результатов:
  - Все вакансии
  - Топ-N по зарплате
  - Фильтрация по ключевым словам
  - Фильтрация по диапазону зарплат
  При необходимости фильтрацию по зарплате можно выполнить после фильтрации по ключевым словам.

## Тестирование
'poetry add --group dev pytest'

Тестирование работы функций проводить через соответствующие модули тестирования в директории tests
